### ⭐ 三道闸门怎么跑（2026-10-08 定，**每次刷机前**）

```bash
# 闸门1：导出集合
python3 tools/gate_new_exports.py out/vmlinux.symvers; echo "rc=$?"
# 闸门2：厂商 CRC 真值 —— 输入必须是 493 个厂商 .ko
python3 tools/gate_vko_crc.py out/vmlinux.symvers \
    ../vendor-ko/vendor_dlkm ../vendor-ko/system_dlkm; echo "rc=$?"
# 闸门3：全量模块审计（缺失 + CRC，必须都为 0）
python3 tools/gate_all_modules.py <内核树> ../vendor-ko/vendor_dlkm ../vendor-ko/system_dlkm; echo "rc=$?"
```

**通过标准**：
- 闸门1：**命中厂商 新增=0 且 消失=0**，且**遮蔽=0**（导出集差异 ∩ 厂商引用名 = ∅），`rc=0`
  - ⚠️ `新增=N 消失=M` 是**原始计数，不要求为 0**；只要**不命中厂商**就 PASS（2026-10-03 权威口径）
  - ⚠️ 早期文档写的"新增=0 消失=0"是**过时的严格模式**（只对未动导出集的 opt5 基线成立），**已作废**
- 闸门2：`会拒绝装载的模块 = 0`（**opt49-crc 起**；在此之前基线是 1 = `system_dlkm/bluetooth.ko` 的 `sk_filter_trim_cap`）
- 闸门3：`VERDICT: PASS`（**缺失 = 0 且 CRC 不符 = 0**）

⛔ **调用方必须传参、必须看 rc、必须 `|| exit 1`**。旧脚本里的
`gate_new_exports.py 2>&1 | tail -5` 不传参且不看 rc，那是**空过**（opt13 那次就是空过）。
退出码：`0` 通过 / `1` 会挂模块 / `2` 输入错误。

**厂商 `.ko` 输入**（`..\vendor-ko\`，493 个 = 433 vendor_dlkm + 60 system_dlkm，151.7 MB）。
取法见 `闸门与判据.md` §三（`adb pull` 会被 Permission denied 拒，必须先 `su -c cp` + `chmod`）。

## ⭐ 通道与环境坑（2026-10-02 新增/复现）

### WSL ↔ PowerShell 引号

- ⛔ **`$(...)` 和 `$var` 经过 `wsl -d ... -- bash -lc "..."` 时会被 PowerShell 先吃掉**。
  今天连续踩了 5 次（`$D` 变空、`$var` 丢失）。
  ⇒ **凡是要在 WSL 里跑多行/带变量的逻辑，一律写成脚本文件再 `bash file.sh`**，
  不要塞进 `bash -lc "..."`。
- ⚠️ `cmd | tail` 会**冲掉退出码** ⇒ 闸门脚本不要接 `| tail`。
- ⛔ **不要用 `find . -name '*.rej' -delete`** —— 仓库里有 **58 个被 track 的 `.rej`/`.orig` 历史垃圾**
  （`lib/zstd/*.rej` 等），删掉会让工作区脏、diff 变成 −29673 行。安全做法：`patch --reject-file=/dev/null`。
- ⚠️ commit message 里有中文双引号/特殊字符时，**别用 `git commit -m "..."` 塞进 `bash -lc`**（引号会断），
  写成消息文件用 `git commit -F <file>`。

### 编译器

- 构建前**必须** `export PATH=/home/builder/kwork/kernel_manifest/workspace/toolchains/clang/bin:$PATH`。
  ⛔ 忘了会用到系统的 clang 18.1.3 ⇒ `out/.config` 里 `CC_VERSION_TEXT` 变成
  `Ubuntu clang version 18.1.3`（实测踩过，可从 config 里看出来）。
- 目标 clang 是 **17.0.2**（GKI 自带，`Android (10087095, +pgo, +bolt, +lto, -mlgo, based on r487747c)`）。

- ACK 权威源是 `android.googlesource.com/kernel/common`，分支 **`android14-6.1`**（不是 `-lts`；
  `-lts` 落后，tip 2025-11-19 vs 主线 tip 2026-09-29）。
- ⛔ **`android.googlesource.com` 在国内被 DNS 污染/墙**，需要路由器代理走通。
  症状：DNS 返 `198.18.0.x`（fake-ip 段）但 TLS 握手失败 ⇒ 代理的 **出站节点**没工作
