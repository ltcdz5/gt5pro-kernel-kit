# 真我 GT5 Pro 自编内核记录：sched_ext/hmbird 接口对齐与 493 模块审计

> 本文由 **DeepSeek** 协助机主整理并撰写。

## 做了什么

用 DeepSeek 协助，给一台真我 GT5 Pro（RMX3888 / SM8650 / ColorOS 16）自编内核（6.1.141）：

- 补齐 ACK 回移；
- 把 sched_ext / hmbird 的接口按**出厂内核**逐条对齐；
- 修掉蓝牙相关的 CRC 定点问题；
- 给设备上的 **493 个厂商模块**做了一遍"能否装载"的全量审计。

## 为什么做

只是想让这台机器在调度这块少一点将就；也想把过程、判据和工具留下来，给后来的人省点弯路。

- 工具与档案（审计 / 闸门 / 记录）：https://github.com/ltcdz5/gt5pro-kernel-kit

## 谨慎说明

目前仍在验证阶段，"接口出现"不等于"调度可用"。

此前有一次整机硬挂死并由 PMIC 复位（opt43），所以本版**不建议普通用户刷入**，也不建议主动 register 任何 scx 调度器。
