# gt5pro-kernel-kit · 自编内核工具箱

**一句话**：改内核最怕把厂商模块搞崩 —— 这个仓库把「有没有搞崩」变成三个能跑出来的数字。

> 作者：**github@ltcdz5** ／ **酷安@天玑1100逆天功耗** ｜ 由 DeepSeek 协助整理

## 三道关卡（每次出片后必跑）

| 关卡 | 看什么 | 现状 |
|---|---|---|
| 厂商模块审计 | 设备上每个厂商模块需要的符号是否都满足 | **493 个：缺失 0、CRC 不符 0** |
| 导出遮蔽 | 新增导出有没有遮蔽厂商同名符号 | **0** |
| 拒载检查 | 有没有模块因版本变化被拒载 | **0** |
| 导出基准 | 导出符号表是否逐名不变 | **15489 个，逐名一致** |

## 目录速览

| 目录 | 内容 |
|---|---|
| `tools/` | 关卡脚本、镜像校验、重打包 |
| `模块/fengchi-boot/` | 风驰自启模块的源码（3 个文件）|
| `档案/` | 过程档案：风驰全过程、当前状态与版本对齐 |
| `configs/` 、 `refs/` | 构建配置与基线参考数据 |
| `archive/` | 归档（不再使用但保留可追溯）|
| `CHANGELOG.md` | 每一步做了什么、数字多少、结论如何 |

## 常用命令

```bash
bash builder_6.1.141.sh            # 构建（工具链路径按本机调整）
python3 tools/gate_all_modules.py  # 关卡一：厂商模块
python3 tools/gate_new_exports.py  # 关卡二：导出遮蔽
python3 tools/gate_vko_crc.py      # 关卡三：拒载
python3 repack_any.py              # 生成刷机包
```

## 风驰是怎么跑起来的（一句话）

**内核负责提供风驰要用的 `scx` 调速器；用户态由 `fengchi-boot` 模块负责「开机准备好 + 玩游戏时切过去」。**
