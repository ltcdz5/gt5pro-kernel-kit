# 为什么这个目录里没有 `lunar_bsp_ext_sched.ko`

因为 **那个 .ko 不是本项目的代码**，而是第三方（LunarKernel 项目 / 作者 Cloud_Yun，**GPL v2**）的编译产物。

**再分发 GPL v2 二进制时必须提供对应源码**，而本项目**没有它的源码**，也**无法证实**手上的二进制
与上游源码一致（它是为本机内核树专门编译的）。

因此公开仓库这里**只提供我们原创的管理脚本外壳**。要用 LSE 模块本体，请自行从上游获取：

- 上游源码：`https://github.com/LunarKernel-Dev/lunarkernel_sched_extention`
- 需要自行按你的内核头文件交叉编译（或从上游发布取得构建）

⚠️ 上游 LSE 据社区情报**源自 OPPO `hmbird_gki` 的拆改**；若其中涉闭源代码，再分发风险由发布者承担。

完整分析见仓库根目录《LSE调度扩展-来源合规缺陷与风险告知-20261004.md》。
